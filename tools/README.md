# Tools 索引

独立工具与脚本集合，不依赖 Agent 运行时，可单独执行。

---

## 脚本（scripts/）

按语言分子目录存放命令行脚本。

| 路径 | 说明 |
|------|------|
| — | 暂无 |

## 提示词模板（prompts/）

按场景分类存放高质量提示词，可直接复用或作为 Skill 依赖。

| 路径 | 场景 |
|------|------|
| — | 暂无 |

## 工作流（workflows/）

多步工作流定义（YAML/JSON 编排），描述跨工具的执行序列。

| 文件 | 说明 |
|------|------|
| — | 暂无 |

---

## 新增工具

- 脚本放入 `tools/scripts/<lang>/`
- 提示词放入 `tools/prompts/<category>/`
- 工作流放入 `tools/workflows/`
- 在上方索引表中添加一行
